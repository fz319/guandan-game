🃏 1. 选牌与放回

• 单击牌立即立起；再次单击该牌自身可放平。
• 一键全部放回：按住 Shift 或 Command / Ctrl（触屏开启右上方【⚡ 批量连选】）点击任意已立起的牌，所有立起的牌全员归位。
• Shift 快速连选：点选第一张后按住 Shift（或开启【⚡ 批量连选】）点另一张未选牌，区间内所有牌连选立起。
• 点击空白处一键收回所有牌。

🎯 2. 全向滑动与拖拽

• 全向自由滑动：在手机端竖屏可随心左右平移划动屏幕，随时查看 27 张牌的完整序列。
• 边缘自动滚屏：拖拽卡牌靠近屏幕上下边缘时，页面自动平滑向下/向上滚动。
• 拖到底部虚线槽自动开辟新的一层。

📑 3. 多方案对比与存档

• 点击标签栏 “+ 新建方案” 尝试全新理牌思路。
• 点击 “📊 方案横向对比” 可横向对比不同版本的打法结构。
• 点击 “💾 保存当前存档” 可自主命名长久保存，日后随时打开继续理牌。

⚙️ 4. 整层调序与残局调牌

• 按住每层左侧的 “≡ 手柄” 可上下调换整层顺序。
• “自定义选牌/调牌”可在 108 张全牌库中自定手牌或残局。
• 电脑键盘按 Delete / Backspace 亦可快速删除立起牌。
